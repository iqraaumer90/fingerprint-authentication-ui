# Fingerprint Authentication UI

A modern and professionally designed Biometric Authentication UI built using **Flutter** and **Dart**.

## About the Project

This project showcases a clean, modern fingerprint authentication interface with a focus on visual design, user experience, and Flutter UI development.

## Features

- Modern fingerprint authentication design
- Clean and user-friendly interface
- Attractive colors and typography
- Responsive mobile UI

## Technologies Used

- Flutter
- Dart
- Material Design
